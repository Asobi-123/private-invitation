# 专属邀约 Private Invitation

[English](README_EN.md)

一款 SillyTavern 扩展。把主页变成一个会"主动走出来找你"的角色召回入口——随机展示你选中的角色，配上专属台词、整张角色封面、可选的挽留与生气文案，把角色重新带回你的视野。

> 这个插件解决的不是"没有角色"，而是角色库变大后，你忘了该回去找谁。

---

## 它能做什么

### 主页召回
- 打开 SillyTavern 主页，从你选中的角色池里随机抽一个出现
- 整张角色封面铺满，配你为这个角色保存的台词
- 三种展示方式：**弹幕**（多条横向漂浮）/ **气泡**（9 宫格定位）/ **横幅**（底部电影字幕条）
- 点"进入"直接切到角色聊天；点"拒绝"按概率触发**挽留**第二次召回

### 每角色独立文案池
- 每个角色单独保存"主邀约文案"和"挽留文案"
- 主页召回**只读已保存文案**，不会临时调用 AI——速度快、行为稳

### AI 辅助生成草稿
- 在控制台**离线**生成台词草稿，用户挑选后入池
- 喂给 AI 的素材：角色卡、聊天记录楼层、世界书条目
- 内置预设：主邀约 5 个、挽留 5 个、生气 8 个
- **自动分批**：聊天楼层多时按"每批 N 楼"自动连续发送，最后合并所有草稿
- 生成中可随时取消，已完成的批次保留

### 生气模式
- 累计拒绝某个角色到阈值（默认 5 次），下次召回触发"生气"形态
- 红黑暴走视觉，倒计时强制进入聊天
- 配套独立的生气文案池和 AI 草稿生成
- 接受邀约时自动归零（可关）

### 视觉定制
- 8 个内置 CSS 模板（极简黑白 / 霓虹边框 / 复古 / 宫廷 / 哥特暗影 / 柔光 / 漫画分镜 / 赛博梦境）
- 自定义 CSS（可保存为模板）
- 让 AI 帮你写 CSS

### API 模式
- **共享模式**（默认）：用 SillyTavern 当前的 API，零配置
- **独立模式**：填 OpenAI 兼容接口，可保存多个档案随时切换
- 独立模式经 SillyTavern 后端转发，HTTPS 酒馆页面也能用 HTTP API URL（绕开浏览器 mixed-content）

## 安装

### 方法一（推荐）— SillyTavern 内安装
1. 扩展菜单 → 安装扩展
2. 填入：`https://github.com/Asobi-123/private-invitation`
3. 刷新页面

### 方法二 — 命令行手动
```bash
cd SillyTavern/data/default-user/extensions/
git clone https://github.com/Asobi-123/private-invitation.git
```
刷新 SillyTavern 页面。

## 第一次使用：5 步入门

> 假设插件已装好。

### 第 1 步：打开控制台
SillyTavern 顶部 extension menu → 找到 **专属邀约** → 点开。
弹出一个居中控制台，顶部有几个 tab。

### 第 2 步：选择会出现在主页的角色
切到 **邀约角色** tab：
- 勾选你想被主页召回的角色
- 建议先选 3–5 个测试，太多会冲淡每个出现的概率
- 一个都不选 = 所有角色都可能出现

### 第 3 步：给角色写台词
切到 **文案** tab：
- 搜索框选当前角色
- 在"主邀约文案池"里手动添加台词（输入框敲回车保存）
- 也可以切到 **AI 生成** tab 让 AI 写草稿，再挑选入池

> **AI 生成是什么？**
> 插件读取角色卡 + 你指定的聊天楼层范围 + 世界书，让 AI 生成多条"角色风格"台词草稿。这些草稿不会自动用，要你手动加入文案池后，才会出现在主页召回里。

### 第 4 步：调整视觉
- **风格** tab：选展示方式（弹幕 / 气泡 / 横幅）、字号、透明度、容器尺寸
- **外观** tab：封面动效、9 宫格气泡位置、内置 / 自定义 CSS、AI 写 CSS

### 第 5 步：启用主页自动召回
**运行控制** tab（或设置抽屉）：
- 启用功能
- 主页自动弹出
- 选弹出策略（详见下方）

回到 SillyTavern 主页，角色就会自己出现了。

## 关键概念解释

### 楼层 / chunk / 分批

聊天记录每一条消息叫一"楼"。聊天有几百楼时不可能一次塞给 AI，所以插件按"每批楼层数"自动分批。

```
聊天有 80 楼，你设置：
  起始楼层 = 0
  结束楼层 = 80
  每批楼层数 = 20

插件自动跑：
  第 1 批：发送 0–19 楼 → AI 出一批草稿
  第 2 批：发送 20–39 楼 → AI 出一批草稿
  第 3 批：发送 40–59 楼 → AI 出一批草稿
  第 4 批：发送 60–79 楼 → AI 出一批草稿
  全部合并 → 入草稿池
```

按钮变身："✕ 取消生成 (2/4)" 显示进度，再点一次取消。**已生成的草稿保留**。

### 过滤 / 排除标签（chip 池）

聊天记录里如果有大量元数据干扰 AI（思考过程、系统标签、HTML 节点），用 chip 池排除：

- **过滤标签（绿色 chip，白名单）**：只保留 `<tag>...</tag>` 包裹的内容
- **排除标签（红色 chip，黑名单）**：剥掉 `<tag>...</tag>` 包裹的内容

支持带任意属性的标签——填 `div` 也能排掉 `<div class="x">...</div>` 整段。

> **HTML 注释和 img 标签**这些不是配对标签，靠"剥离 HTML 注释和 img 标签"开关（默认开）处理，覆盖 `<!-- ... -->`、`<img>`、`<br>`、`<hr>` 等。

### 主页自动弹出策略

| 策略 | 行为 |
|---|---|
| 每次刷新 / 加载页面后弹一次 | 每次 SillyTavern 启动展示一次 |
| 按冷却分钟数定时再弹 | 距上次弹出超过 N 分钟再弹 |
| 每次回到主页都弹 | 离开聊天回主页就弹 |
| 只手动测试（不自动弹） | 关闭自动，靠 manual 触发 |

## 三种召回形态

| 形态 | 触发 | 行为 |
|---|---|---|
| **主邀约** | 主页自动 / 手动 | 标准召回，可拒绝 |
| **挽留** | 拒绝主邀约后按概率触发 | 第二次召回，再拒绝就关 |
| **生气** | 累计拒绝达阈值（默认 5 次） | 红黑暴走风格，倒计时强制进入 |

每种形态独立的文案池 + 独立的 AI 草稿生成。

## 部署兼容

可在以下环境运行：
- `localhost`
- 普通 HTTP
- HTTPS
- 纯 IP VPS（例 `http://203.0.113.10:8000`）

独立 API 模式经 SillyTavern 后端转发，不由浏览器直接请求 API URL。HTTPS 酒馆页面也可以配 HTTP 的独立 API 地址。
